# Oscorp Industries - Banner Responsivo

Uma landing page temática da Oscorp Industries desenvolvida como atividade prática de **Media Queries e Imagens Responsivas**, utilizando apenas HTML e CSS. O projeto explora técnicas profissionais de responsividade com a tag `<picture>`, adaptando o banner principal para Desktop, Tablet e Mobile.

---

## Sobre o Projeto

Este projeto consiste em uma página temática da Oscorp Industries, empresa fictícia do universo Marvel, desenvolvida para a atividade de **Media Queries e Imagens Responsivas**.

A proposta foi criar uma interface futurista e tecnológica, aplicando na prática os conceitos de responsividade vistos em aula - com troca automática de imagens por dispositivo, uso da tag `<picture>`, variáveis CSS, Flexbox, Grid e animações com `@keyframes`.

O objetivo principal foi demonstrar o uso de Media Queries e imagens responsivas em um contexto real, construindo uma interface moderna sem frameworks ou JavaScript.

---

## Funcionalidades

- Banner principal responsivo com `<picture>` (Desktop / Tablet / Mobile)
- Loader animado de entrada
- Header fixo com efeito glass e backdrop-filter
- Hero section com animação neon e HUD de status
- Seção de histórico em linha do tempo
- Cards de divisões com status (Ativo / Restrito / Em Progresso)
- Galeria com efeito hover e overlay animado
- Cards de projetos futuros com barra de progresso
- Scroll indicator animado
- Layout totalmente responsivo (480px / 768px / 1024px)

---

## Tecnologias Utilizadas

- HTML
- CSS

---

## Conceitos Aplicados

- Tag `<picture>` com `<source>` e `srcset` para imagens responsivas
- Media Queries com breakpoints em 480px, 768px e 1024px
- Variáveis CSS (`--verde`, `--fundo`, `--cinza`, `--branco`)
- Flexbox e CSS Grid
- Animações com `@keyframes` (loader, piscar, rolarMouse)
- Efeito hover com `transition`
- `display: none` / `display: block` para controle por breakpoint
- `backdrop-filter` e `box-shadow` para efeitos visuais

---

## Objetivos do Projeto

- Aplicar a técnica profissional de imagens responsivas com `<picture>`
- Praticar Media Queries para diferentes dispositivos
- Utilizar variáveis CSS para manutenção da identidade visual
- Construir layout com Flexbox e Grid
- Desenvolver animações com `@keyframes`
- Criar uma interface moderna e responsiva sem JavaScript

## Aprendizados

Durante o desenvolvimento deste projeto foi possível aprender:

- Uso profissional da tag `<picture>` com múltiplas sources
- Criação de Media Queries para Desktop, Tablet e Mobile
- Aplicação de variáveis CSS em projetos reais
- Construção de layouts responsivos com Grid e Flexbox
- Desenvolvimento de animações com `@keyframes`
- Responsividade de imagens com `object-fit: cover`
- Efeitos visuais modernos com `backdrop-filter` e `text-shadow`
